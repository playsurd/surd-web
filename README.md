# surd

fast unblocked games. one page, nothing to install.

every game here has been opened in a real browser and checked that it actually
starts — no dead links, no black screens.

## some of what's on it

hollow knight · celeste · terraria · miside · clover pit · antonblast ·
untitled goose game · brotato · amanda the adventurer · that's not my neighbor ·
minecraft (a bunch of versions) · geometry dash · slope · every papa's game ·
100+ flash games · friday night funkin' and most of its mods

## notes

games are community web ports — the people who made them are credited on the
game screen next to the original devs. if you ported something here and want
your name on it (or off it), open an issue.

rights holder and want something gone? email playsurd@protonmail.com and it goes.
