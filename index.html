My Games

Drop a game folder or .zip here
Name the folder what you want the game called (use underscores for spaces, like My_Cool_Game). Put the game's files in it, with its images and other files in subfolders as usual. It needs an index.html or another .html page to start from.

Games are saved in this browser only, and they run inside Duplicity. Only add games you trust, since a game can read the rest of this site's data in your browser (including your chat login). Games that load files with paths starting at "/" won't find them, and a few that need special browser headers (some multi-threaded builds) may not run.
